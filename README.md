# Calculadora Função Quadratica
Este é um projeto realizado com simples HTML, CSS e JavaScript, onde o objetivo foi criar um calculadora que mostrava seu raciocínio em calculos com funções quadráticas

## Descrição do que a calculadora apresenta

Identifica quando o valor passado não é um número e alerta o usuário inserindo cores de alerta nos inputs
